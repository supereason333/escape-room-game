# Escape room game

This is an escape room made in godot, solve the puzzles and leave the world.

This was made for week 5 of Hack Club's Terra

# How to run the game

You can play the webexport version on my Itch.io https://supereason333.itch.io/escape-room however, it is recommended to play the downloaded version as you have a lower chance of accdentaly closing the tab because the game doesn't save.

The windows version may give a Windows Defender warning and the macos version will require you to click "open anyways" in the privacy settings page as it does not have notorization.

# Controls

WASD => move
Click => interact
C or L-CTRL => crouch
Z => zoom
ESC => ungrab mouse
SPACE => exit view
